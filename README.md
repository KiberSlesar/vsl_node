# vsl_node

Пакет кастомных нод для ComfyUI: генерация промптов через LLM, визуальная галерея стилей и набор полезных утилит.

[English version](README.en.md)

## Установка

Через git clone (рекомендуется — потом легко обновляться):

```
cd ComfyUI/custom_nodes
git clone https://github.com/KiberSlesar/vsl_node.git
```

Перезапустите ComfyUI — ноды появятся в меню категорий `VSL/...`.

Обновление до последней версии:

```
cd ComfyUI/custom_nodes/vsl_node
git pull
```

Можно и просто скопировать каталог в `ComfyUI/custom_nodes/` — результат тот же.

Настраивать после установки ничего не обязательно: пресеты LLM, настройки моделей и избранное создаются автоматически при первом использовании. При желании скопируйте шаблоны `*.example` в файлы без суффикса `.example` — например, `vsl_router_presets.json.example` → `vsl_router_presets.json`.

## Ноды

### VSL Prompt Helper
Берёт ваше описание (например, «девушка в красном платье в саду») и превращает его в готовый промпт для конкретной модели генерации. Нода отправляет запрос в языковую модель (LLM), и та дописывает детали, переводит или упорядочивает теги — в зависимости от выбранного режима.

- **Режимы:** `Enhance` — расширяет и дополняет запрос; `Translate Only` — только переводит; `Skip` — не обращается к LLM и отдаёт текст как есть.
- **Целевые модели:** Krea 2 (реализм / аниме / нейтрально), Anima, Illustrious, Qwen 2.1 text2img, Qwen 2.1 Image Edit, MOSS Image, MOSS Image Layout (раскладка элементов по рамкам).
- **Подключение:** любой OpenAI-совместимый адрес — локальный llama-router, NVIDIA NIM, OpenRouter-подобные шлюзы. Можно указать модель, API-ключ и прокси (`http://` и `socks5://`). Часто используемые подключения сохраняются в пресеты (кнопки Save / Update / Delete) и выбираются из выпадающего списка.
- **Дополнительно:** негативный промпт, вставки extra/quality, анализ лица и эмоций, поддержка bounding boxes для раскладок MOSS.
- **Выходы:** `prompt` (основной промпт), `extra_prompt`, `face_emotion`, `raw_debug` (отладка), `negative_prompt`, `canvas_size`.

### vsl_Style_Selector
Визуальная галерея из 414 стилей с превью, сгруппированными по категориям. Клик по превью выбирает стиль, повторный клик снимает выделение — тогда нода отдаёт пустой текст. Звёздочка в углу превью добавляет стиль в избранное (вкладка `Favorites` показывает только избранное), кнопки −/+ меняют размер превью. На выходе — готовый текст описания выбранного стиля.

### VSL Text Concentrate
Склеивает до четырёх текстовых входов в один с настраиваемым разделителем (по умолчанию запятая). Пустые входы пропускаются.

### VSL Image Size
Замеряет изображение и отдаёт его ширину и высоту (INT), а на панели ноды показывает соотношение сторон, размер в пикселях и мегапикселях.

### VSL Image Resize
Как VSL Image Size, но с коэффициентом умножения: берёт ширину и высоту поданной картинки, умножает их на число из строки коэффициента (например `1.5`, `0.5` или `1,5`) и отдаёт результат. Значения нормализуются — на выходе всегда положительные числа (минимум 1). На панели показывает исходный и новый размер.

### vsl_image_compare
Сравнение двух изображений A/B на одной серой панели: шторка следует за курсором (SLIDE) или кнопки A/B переключают картинку целиком. `image_a` проходит через ноду без изменений — её можно ставить посреди графа. Превью пишутся во временную папку и не засоряют выходы.

### vsl_seed
Сид с кнопками: 🎲 Random, +1, -1, ♻ Last (вернуть предыдущий). Через API поддерживаются магические значения `-1` (случайный), `-2` (инкремент), `-3` (декремент) — сервер сгенерирует сид и запишет его обратно в метаданные воркфлоу.

### VSL Min/Max Size
Из ширины и высоты выбирает большее или меньшее значение (переключатель `max` / `min`) и отдаёт одним числом. Удобно для автоматической подстройки размеров.

### VSL Model Loader (Presets)
Загружает модель диффузии и вместе с ней отдаёт сохранённые настройки генерации: CFG, шаги, сэмплер, шедулер, весовая точность. Наборы настроек сохраняются за моделями и раздаются через HTTP-роуты `/vsl/model-presets*` — не нужно выставлять параметры вручную каждый раз.

### VSL Any Reroute
Универсальный «перемычка» для любых типов данных: принимает и возвращает любой подключаемый сигнал, помогая аккуратно разводить связи на холсте.

## Локальные настройки (не в репозитории)

Рядом с нодами создаются локальные файлы (шаблоны — `*.example`):

- `vsl_router_presets.json` — пресеты подключений LLM (router_url, api_key, model, proxy). **Содержит API-ключи — в git не попадает.**
- `vsl_model_presets.json` — сохранённые настройки моделей.
- `vsl_style_favorites.json` — избранные стили галереи.

Файлы необязательны: ноды работают и без них, файлы создаются автоматически при первом сохранении.

## Примечания

- `web/previews/` — 414 превью стилей для галереи vsl_Style_Selector.
- `vsl_prompts.json` — системные промпты (11 ключей), читаются при импорте; правка требует перезапуска ComfyUI.
